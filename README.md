# TP_labs

# Лабораторная работа 1
# Получение информации об ОС и основных параметрах ПК
# Цель работы
Написать программу на ЯП Python, собирающую данные об операционной системе и аппаратных характеристиках устройства, которая в результате выполнения сохраняет полученные данные в файл формата JSON.
# Стек технологий
* Язык программирования - ```Python 3.14```
* Библиотеки :  ```os```, ```platform```, ```psutil```, ```sys```
* Среда программирования - ```PyCharm```
# Собираемые данные
ОС:
* Название 
* Релиз
* Версия 
* Архитектура
* Система хранения файлов

Аппаратная характеристика:
* Количество логических процессоров
* Оперативная память устройства (ГБ)
* Объём памяти системного диска (ГБ)
* Свободно на системном диске (ГБ)

# Внешние модули
Для выполнения работы была использована внешняя библиотека ```psutil```. 

С её помощью можно получить информацию о системных ресурсах устройства (ЦП, оперативная память, диски...), но главное преимущество и причина, по которой была выбрана эта библиотека, - кроссплатформенность. Это позволяет удобно написать программу, которая будет работать на любой ОС.

Установка:
```bash
pip install psutil
```
# Запуск программы
Для начала работы программы запустите: 
```bash
scrirt.py
```
